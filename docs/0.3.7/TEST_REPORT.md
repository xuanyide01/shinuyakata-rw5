## 四、本版修复的缺陷（均由本轮测试发现）

1. **章节/存档标题泄漏源标签**：显示 `s303 · *dummyselect1` → 改为「第3章 · 303 分歧」。
2. **立绘拉伸变形**：原先统一拉伸到 320×254 → 改为按序列帧的宽高比显示。
3. **EXTRA 只显示 2 组且布局溢出**：58 组挤在一屏、文字重叠 → 改为分页（4 组/页、15 页、带页码）。
4. **CG 未进鉴赏**：仅旧版 2 张 → 全部 392 张背景/CG 中的 56 组事件画面入册。
5. **s304_1 补丁列错位**：说话人与正文互换 → 改用结构正确的 data 版并补译 169 条。
6. **说话人/正文日文名残留**：统一为中文，残留 0。
7. **结局说明文案过期**：仍写「本版含明确省略段落」→ 改为全剧情收录说明。
