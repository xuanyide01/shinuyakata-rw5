# 《死馆》RW5 · 0.3.6 界面重制

作者 xuanyide；本轮界面与工具由 Codex 完成。2026-11-04。

本版以用户提供的 DeepSeek 0.3.5 为基础，仅更新 UI。安装包 14,552,193 B（约 14.55 MB），比 0.3.5 增加 62,448 B，低于 25,000,000 B。BIN 与 RPK 字节相同。

- 标题使用原作 NEW GAME、LOAD GAME、GALLERY、CONFIG、END GAME 字标，以及原作红色按压态；统一左对齐。
- 对话框、菜单、章节、存档、设置、鉴赏、选项、确认及结束页面统一为冷紫色面板、细线边框和低亮度烛台纹饰。
- 标题文字及主要控件留出圆角安全距离，长列表标题采用省略或两行排版；鉴赏翻页统一到底栏。
- 阅读菜单右上角接入原有「章节选择」功能，直接调用已有 openChapters，不改变章节或路线逻辑。

剧情、背景/CG/立绘、翻译数据、引擎和字库与 0.3.5 逐字节一致。本轮没有审核、改写或扩充原包剧情和相关素材，也不重新评价其内容完成度。有效的 0.3.5 存档仍使用同一包名、同一读写逻辑和键名。

12 项现有测试通过，签名/CRC/包内摘要及 UI 改动范围检查通过。最终实际包已在 Vela 原生模拟器冷启动检查；鉴赏、差分、长文、选项及第30栏存读档另使用相同 UI 的隔离占位测试包检查。本版实机与长期运行测试仍待完成。

使用表盘自定义工具传输后，等待手表完成安装。交接细节见 UI_HANDOFF_0.3.6.md；UI 补丁不包含原作剧情或 CG，完整工作工程在 D:/codex/移植项目/shinuyakata-rw5/源码-UI-0.3.6。
