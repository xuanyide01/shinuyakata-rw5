# 《死馆》RW5 · 0.3.7 UI 修复

作者：xuanyide。基础内容由 DeepSeek 提供，本轮 UI 修复由 Codex 完成。

本版修复用户反馈的三项问题：

- **END GAME 真正退出**：关闭逐字、自动及延迟刷新计时器，取消过期读取回调，再调用系统退出接口。
- **菜单自动／速度即时生效**：把固定key的循环菜单改成独立文本按钮，直接绑定自动状态和速度标签。自动播放从菜单返回后推进，在选项处暂停；速度有三档并保存设置。
- **菜单等界面全屏遮挡**：非阅读界面隐藏场景显示，额外铺设432×514不透明底层，并给面板设置实色背景。菜单、设置、存读档、章节、鉴赏和选项页边缘不再透出场景。

版本0.3.7 / code95，包名com.codex.yakata.rw5，安装包14,552,289 B（约14.55 MB）。BIN/RPK相同。剧情、翻译、CG、立绘、引擎、字库和存档格式未修改；0.3.5、0.3.6旧交付保留。

15项测试通过；实际包验证菜单标签切换和退出生命周期；隔离UI包验证自动推进到选项，以及14个面板/状态的边缘无纯色测试场景漏出。七个关键安装文件已从模拟器拉回，与最终包一致。新版本仍待实机复测。

通用Vela模拟器没有系统HOME桌面，退出后显示黑屏，但日志已确认应用关闭和资源销毁；实机返回桌面的显示效果需在手表确认。
